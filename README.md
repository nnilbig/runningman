# 跑者murmur（試玩版）

一款以跑步為主題的 3D 網頁小遊戲。主角阿傑從三十二歲某個清晨開始跑步，十個章節、十年的時間，從第一次跑三公里、加入又離開跑團、第一場全馬、一百公里超馬，到成績不再進步、失去熱情，最後回到同一條河堤。

> 靈感來自村上春樹《關於跑步，我說的其實是……》中的人生階段與主題。劇情與台詞皆為原創，未引用原文。

## 怎麼玩

直接用瀏覽器開啟 `index.html`，或到 GitHub Pages 的網址遊玩。手機、電腦都可以。

| 操作 | 按鈕 | 鍵盤 |
|---|---|---|
| 左右閃人 | ◀ ▶ | ← → / A D |
| 調整配速 | ▲ ▼ | ↑ ↓ / W S |

- 預設配速 6'00"/km，每章實際遊玩約 1 分鐘，畫面上的距離與時間照真實配速換算。
- 心率衝到 Zone 5 會有警告，撐太久會被迫放慢。

## 技術

- 單一 HTML 檔，[three.js r128](https://threejs.org/) 從 CDN 載入，沒有其他相依套件。
- 低多邊形、平面著色（flat shading）的粉彩風格；場景、人物皆為程式生成，無外部美術素材。
- 進度（「你為什麼跑？」的答案、全馬成績）存在瀏覽器的 localStorage。

## 部署到 GitHub Pages

Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `root`，存檔後約一分鐘就能用 `https://<帳號>.github.io/runningman/` 開啟。
